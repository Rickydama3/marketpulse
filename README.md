# MarketPulse

MarketPulse is a Machine Learning project that studies the relationship between stock prices and financial news sentiment.

## Features

- Historical stock market analysis
- Financial sentiment analysis
- Price direction prediction
- Interactive dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- yfinance
- NLTK

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
